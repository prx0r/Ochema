## Corrected central thesis

Levin's defensible thesis is:

[
\boxed{
\text{Morphogenesis instantiates empirically measurable problem-solving capacities
continuous with some capacities conventionally classified as cognition.}

That is stronger than saying morphogenesis merely resembles cognition, but weaker than saying all morphogenesis is consciousness or literal mentality.

Levin explicitly presents morphogenesis as basal cognition and emphasizes a symmetry between problem-solving in anatomical, physiological, transcriptional, and behavioural spaces. # I. What the 2026 chapter actually establishes

The chapter was posted by Levin on May 31, 2026, as his contribution to the forthcoming volume *Open Questions in Developmental Biology*. It is a position chapter expressing his interpretation of developmental biology, not a single experimental paper establishing every component of the synthesis. ([Forms of life, forms of mind][2])

Its central argument can be reconstructed as follows.

## The morphogenetic competency argument

Let (S) be a developmental system, (G) a terminal anatomical state, and (D) a class of perturbations.

Define goal robustness:

[
R_G(S)
======

P\big(S\rightarrow G\mid D\big)
]

Define pathway variability:

[
V_G(S)
======

\left|
\left{
\pi:
S\xrightarrow{\pi}G
\right}
\right|
]

where (\pi) is a developmental trajectory.

A rigid mechanism can reach (G) through one narrow trajectory:

[
V_G(S)\approx1
]

A competent system can reach (G) through multiple context-dependent trajectories:

[
V_G(S)\gg1
]

while retaining:

[
R_G(S)\gg0
]

Therefore, when a system reaches approximately the same outcome by different means under novel perturbations, its behaviour cannot be completely characterized by a single fixed trajectory.

[
\boxed{
R_G(S)\gg0
\land
V_G(S)\gg1
\Rightarrow
\text{regulative competency}
}
]

This is valid.

What does **not** follow deductively is:

[
\text{regulative competency}
\Rightarrow
\text{phenomenal cognition}
]

The strongest conclusion is:

[
\boxed{
\text{The system belongs on a graded continuum of goal-directed competency.}
}
]

# II. The spectrum of persuadability is operationally powerful

The spectrum of persuadability is one of Levin's strongest conceptual tools because it avoids deciding agency from appearance or substrate.

Let (I_k) be an intervention class:

[
I_1=\text{direct physical reconstruction}
]

[
I_2=\text{setpoint modification}
]

[
I_3=\text{training or reinforcement}
]

[
I_4=\text{symbolic or high-level communication}
]

For a system (S), define:

[
P_k(S)
======

\text{effectiveness of }I_k\text{ in predictably redirecting }S
]

A system's persuadability profile is:

[
\mathbf P(S)
============

\langle
P_1(S),P_2(S),P_3(S),P_4(S)
\rangle
]

This replaces the binary question:

[
\text{"Is }S\text{ intelligent?"}
]

with:

[
\text{"Through which intervention spaces can }S\text{ be controlled?"}
]

That is a genuine methodological advance.

But the scale is not automatically a single intelligence axis. A system may be highly susceptible to one intervention class and insensitive to another. Therefore it is better represented as a vector than a ladder:

[
\boxed{
\mathbf P(S)\in\mathbb R^n
}
]

not necessarily:

[
S_1<S_2<S_3<S_4
]

A human may require molecular intervention for one process and symbolic communication for another. A tissue may exhibit training-like plasticity without possessing language-level capacities.

# III. "Same goal by variable means" requires careful goal attribution

William James's formulation is useful:

[
\text{intelligence}
\approx
\text{fixed ends achieved through variable means}
]

But every apparent goal attribution has rival explanations.

Suppose:

[
S\xrightarrow{\pi_1}G
]

normally, and after perturbation:

[
S'\xrightarrow{\pi_2}G
]

with:

[
\pi_1\neq\pi_2
]

There are at least three interpretations:

1. **Goal representation**

   [
   S\text{ explicitly encodes }G
   ]

2. **Distributed attractor dynamics**

   [
   G\text{ is a stable attractor of }\Phi
   ]

3. **Selection-shaped local rules**

   [
   \text{local policies collectively produce }G
   ]

The observation alone does not distinguish them.

Therefore:

[
\text{equifinality}
\not\Rightarrow
\text{explicit representation of a goal}
]

But it does establish something important:

[
\boxed{
\text{The causal organization must explain robustness across trajectories,
not merely replay one developmental sequence.}
}
]

Levin's framework is strongest when "goal" means a counterfactually recoverable attractor or target state, rather than a consciously imagined outcome.

# IV. Bioelectricity is cognitive glue—but not the whole intelligence

The mechanism is broadly correct:

[
\text{ion channels}
\rightarrow
V_{\mathrm{mem}}
]

[
\text{gap junctions}
\rightarrow
\text{intercellular voltage coupling}
]

[
\text{voltage-sensitive channels}
\rightarrow
\text{recursive network dynamics}
]

This enables multicellular bioelectric states to integrate information across tissue scales. Levin's research programme treats these networks as an important mechanism by which cellular competencies can be coordinated into larger-scale goals. ([PubMed][3])

But the claim should not be:

[
\text{bioelectricity}
=====================

\text{morphogenetic cognition}
]

Morphogenesis involves interacting:

[
{
\text{gene regulation},
\text{bioelectric signalling},
\text{biochemical gradients},
\text{mechanics},
\text{cell migration},
\text{metabolism},
\text{extracellular structure}
}
]

Bioelectricity is therefore better described as a coordination and memory medium:

[
\boxed{
B
=

\text{one major mechanism for scaling and stabilizing collective competency}
}
]

not the unique physical substance of agency.

# V. The brain–body continuity claim is strong

The proposed continuity is:

[
\text{slow bioelectric navigation of morphospace}
\longrightarrow
\text{fast bioelectric navigation of behavioural space}
]

This should be understood as an evolutionary and mechanistic continuity, not as an identity of function.

Both neural and non-neural tissues use:

* ion channels;
* membrane potentials;
* electrical coupling;
* neurotransmitter-like signalling;
* state-dependent plasticity.

Levin's 2023 "cognitive glue" paper explicitly argues that evolution used bioelectric signalling before nervous systems to coordinate morphogenesis, and that nervous systems accelerated and extended mechanisms already employed for anatomical regulation. ([PubMed][3])

The defensible claim is:

[
\boxed{
\text{Neural cognition elaborates ancient mechanisms of distributed physiological coordination.}
}
]

Not:

[
\boxed{
\text{development and thought are literally the same computation at different speeds.}
}
]

Their architectures overlap, but their state spaces, time constants, embodiment and outputs differ.

# VI. The cognitive light cone is a control-domain model of selfhood

The draft's strongest formalizable concept is the cognitive light cone.

Let (S) be a system and (z) some variable.

Define:

[
z\in\mathcal L(S)
]

iff (S):

1. detects information relevant to (z);
2. distinguishes desirable from undesirable states of (z);
3. possesses actions that can alter the probability distribution over (z);
4. maintains this relation across some temporal interval.

Formally:

[
\mathcal L(S)
=============

\left{
z:
I(S;z)>0
\land
\exists G_z
\land
\exists a
\left[
P(G_z\mid do(a))
\neq
P(G_z)
\right]
\right}
]

This yields graded agency:

[
\mathcal L(\text{single cell})
\subset
\mathcal L(\text{tissue})
\subset
\mathcal L(\text{organism})
]

in some cases.

The computational-boundary paper explicitly defines a self through the spatiotemporal range of events it can measure, model and attempt to affect. ([PubMed][1])

But this is a functional self:

[
S_{\mathrm{functional}}
]

It does not yet establish a phenomenal subject:

[
S_{\mathrm{phenomenal}}
]

Therefore:

[
\boxed{
\mathcal L(S)\text{ individuates a domain of agency, not automatically a field of experience.}
}
]

This distinction must remain explicit.

# VII. Cancer as cognitive-light-cone contraction

The cancer interpretation can be expressed as:

[
\mathcal L(\text{cell in tissue})
\rightarrow
\mathcal L(\text{cell alone})
]

A cell whose behaviour was formerly constrained by organism-scale signals becomes dominated by local proliferation and survival policies.

This is a productive systems-level model:

[
\text{cancer}
\approx
\text{breakdown of multiscale coordination}
]

However, three corrections are necessary.

First, cancer is heterogeneous. Not every cancer is primarily caused by gap-junction loss or bioelectric decoupling.

Second, restoration of bioelectric states can normalize some oncogene-induced phenotypes in particular experimental systems, but this is not a general clinical result that bioelectric coupling cures cancer.

Third, "smaller self" is a functional interpretation of changed control scope, not evidence that a cell's phenomenal self contracts.

Thus:

[
\boxed{
\text{Cancer can sometimes be modelled as a collapse from organism-level
coordination toward cell-level objectives.}
}
]

Grade:

[
C
]

as a general explanatory framework, with stronger evidence for specific mechanisms and experimental models.

# VIII. The experimental examples require different evidential grades

## 1. Planarian anatomical memory

Planarian polarity can be altered by transient bioelectric intervention, and altered regeneration outcomes can persist across later rounds of cutting despite unchanged genomic sequence. Levin's publication list includes experimental and computational work on persistent bioelectrically induced changes in planarian regeneration. ([Levin Lab][4])

Supported:

[
\boxed{
\text{Anatomical target information is not exhausted by DNA sequence.}
}
]

Not proven:

[
\boxed{
\text{The target exists as a consciously represented goal.}
}
]

Grade:

[
B
]

for persistent non-genetic pattern memory;

[
D
]

for conscious goal representation.

## 2. Scrambled tadpole faces

Perturbed craniofacial structures can move along abnormal paths and nevertheless achieve comparatively normal configurations. The relevant 2012 paper is listed in Levin's publication record. ([Levin Lab][5])

Supported:

[
\boxed{
\text{Development is regulative and can reach target morphology through
noncanonical trajectories.}
}
]

Grade:

[
B
]

## 3. Enlarged kidney cells

The important conclusion is multiple realizability of a morphological outcome:

[
G
=

\text{tubule formation}
]

may be achieved through different lower-level mechanisms depending on cellular scale.

This supports:

[
\boxed{
\text{The macro-level outcome is not identical to one fixed microscopic procedure.}
}
]

It does not alone establish deliberation or cognition.

## 4. Ectopic eyes

Ectopic sensory organs can become behaviourally functional through unexpected neural interfaces, demonstrating substantial developmental and neural plasticity. Levin's lab explicitly studies plasticity involving ectopic sensory and motor organs and altered CNS topology. ([Levin Lab][6])

Supported:

[
\boxed{
\text{Embodied systems can incorporate novel sensory hardware without
evolutionary pre-specification of the exact interface.}
}
]

Grade:

[
B
]

## 5. Cross-embryo morphogenetic assistance

This claim requires exact citation and protocol specification before assigning grade (B). "Embryos communicate through ion-flux waves" and "develop their own transcriptomes" are too compressed to evaluate as written.

At minimum distinguish:

[
\text{improved group-level resistance}
]

from:

[
\text{intentional cooperative assistance}
]

The first may be experimentally observed. The second is an interpretation.

## 6. Antler trophic memory

Persistent alteration across seasonal regeneration is suggestive of long-term pattern memory distributed beyond the transient antler structure.

But the mechanism may involve:

* the pedicle;
* local nerves;
* scar tissue;
* stem-cell niches;
* systemic signalling;
* epigenetic modification.

Therefore:

[
\text{effect persists after antler replacement}
]

does not imply:

[
\text{non-local memory}
]

unless "non-local" merely means not stored in the shed antler tissue.

Use:

[
\boxed{
\text{long-term distributed morphogenetic memory}
}
]

rather than the stronger and ambiguous "non-local information storage."

# IX. The genome-as-engram claim is insightful but metaphorical

The anti-blueprint conclusion is correct:

[
\boxed{
\text{DNA sequence does not geometrically specify a complete mature anatomy.}
}
]

Genes encode proteins and regulatory interactions. Development depends on cellular interpretation, physical context, feedback, environmental conditions and inherited cellular organization.

However:

[
\text{genome}=\text{memory engram}
]

is a theoretical metaphor, not an experimentally established identity.

The bowtie can be written:

[
\text{evolutionary history}
\xrightarrow{\text{compression}}
G
\xrightarrow[\text{cellular context}]{\text{developmental interpretation}}
P
]

But (G) does not contain a compressed record of every ancestral phenotype in the ordinary information-theoretic sense.

The stronger formulation is:

[
\boxed{
\text{The genome specifies reusable molecular components and regulatory
constraints whose phenotypic meaning is enacted by a competent developmental system.}
}
]

The genome is neither:

[
\text{complete blueprint}
]

nor merely:

[
\text{passive prompt}
]

It is an active component of a larger inherited developmental system.

# X. The agency ratchet is a real evolutionary hypothesis

Let:

[
C_t
]

be lower-level developmental competency and:

[
H_t
]

the degree of precise hardware specification required for viable development.

A competency-buffering hypothesis proposes:

[
\frac{\partial H}{\partial C}<0
]

As competency increases, evolution can tolerate less tightly specified lower-level implementation because developmental processes compensate for perturbations.

This may increase the evolutionary accessibility of novel phenotypes:

[
C\uparrow
\Rightarrow
\text{mutational viability}\uparrow
\Rightarrow
\text{accessible variation}\uparrow
]

Levin's publication record includes work explicitly modelling how cellular competency alters evolutionary dynamics. ([Levin Lab][4])

This is a serious hypothesis.

But "ratchet" implies monotonic self-amplification:

[
C_{t+1}>C_t
]

which need not always occur. Competency can also mask deleterious mutations, accumulate hidden fragility or become costly.

A corrected model is:

[
\Delta C
========

B_{\mathrm{robustness}}
+
B_{\mathrm{evolvability}}
-------------------------

## C_{\mathrm{metabolic}}

C_{\mathrm{hidden\ load}}
]

Therefore the agency ratchet is conditional, not universal.

# XI. Causal emergence does not prove strong downward causation

Let a micro-description be (X) and a macro-description (M=f(X)).

Effective information can be represented roughly as:

[
EI(X)
=====

I(do(X);X')
]

A macro-model exhibits causal emergence when:

[
EI(M)>EI(X)
]

under a specified intervention distribution and model construction.

This means the macro-model is more causally informative, efficient or less noisy for the chosen explanatory task.

It does **not** necessarily mean:

[
M
]

is an additional force acting on (X).

The same underlying dynamics may support a macro-description with better causal signal.

Thus:

[
\boxed{
EI(M)>EI(X)
\Rightarrow
\text{macro-level causal autonomy or informativeness}
}
\]

but not automatically:

[
\boxed{
EI(M)>EI(X)
\Rightarrow
\text{ontologically independent downward cause}
}
\]

The correct Ochema claim is:

[
\boxed{
\text{Some higher-level descriptions may possess objectively superior causal
informativeness and intervention utility.}
}
]

Grade:

[
B/C
]

depending on the specific biological system and measure.

# XII. The final "dual-aspect" inference is too fast

Your unfinished sentence was presumably:

> They are not two processes, but two descriptions of one process.

That is a strong and coherent ontological interpretation:

[
\operatorname{Microchemical}(A)
]

and:

[
\operatorname{Macroagential}(A)
]

refer to the same biological token (A).

But this is initially only **description-level pluralism**:

[
A_{\mathrm{micro}}
\equiv
A_{\mathrm{macro}}
]

It does not yet establish phenomenal dual-aspect monism:

[
A_{\mathrm{physical}}
\equiv
A_{\mathrm{phenomenal}}
]

The first is supported by ordinary scientific interlevel identity. The second faces the explanatory gap.

Therefore distinguish:

### Safe claim

[
\boxed{
\text{Morphogenesis can be described mechanistically from below and
agentically from above without positing two biological processes.}
}
]

### Frontier hypothesis

[
\boxed{
\text{In conscious systems, extrinsic mechanism and intrinsic experience may
be two modes of access to the same causally efficacious process.}
}
]

Levin's work strengthens the first. It provides conceptual support for the second but does not prove it.

# XIV. Sharp ontology that survives

The strongest synthesis is:

[
\boxed{
\text{Living systems are nested, materially enacted control processes whose
effective individuality is determined by the scale of the goals they can
robustly pursue.}
}
]

Let:

[
A_i
===

\langle
X_i,\Phi_i,G_i,\Pi_i,H_i,\mathcal L_i
\rangle
]

where:

* (X_i): accessible states;
* (\Phi_i): embodied dynamics;
* (G_i): recoverable target states;
* (\Pi_i): context-sensitive policies;
* (H_i): history-bearing dispositions;
* (\mathcal L_i): cognitive light cone.

Define competency:

[
K(A_i)
======

\mathbb E_{d\sim D}
\left[
\operatorname{Success}(A_i,G_i\mid d)
\right]
]

Define flexibility:

[
F(A_i)
======

H(\Pi_i\mid G_i,D)
]

where high (F) indicates diverse successful policies under perturbation.

Define an agent:

[
\boxed{
\operatorname{Agent}(A_i)
\iff
K(A_i)>k
\land
F(A_i)>f
\land
\mathcal L_i\neq\varnothing
}
]

This definition does not assume neurons, language, genes, or consciousness.

A phenomenal subject requires an additional condition:

[
\operatorname{Subject}(A_i)
\iff
\operatorname{Agent}(A_i)
\land
\chi(A_i)
]

where:

[
\chi(A_i)
]

is the currently unknown condition under which agency is intrinsically present as experience.

This is the exact frontier.

Levin substantially advances our account of:

[
\operatorname{Agent}(A)
]

He does not yet supply:

[
\chi(A)
]

Therefore the final theorem is:

[
\boxed{
\text{Morphogenesis closes much of the gap between mechanism and agency,
but not the gap between agency and phenomenality.}
}
]

That should become the foundation of Ochema. It is stronger precisely because it does not pretend the remaining bridge has already been crossed.
