# PART 0: THE INTRODUCTION — WHY LAYERS

## 0.1 The Problem of the Thesis

A theory of the structure we have been investigating must satisfy two
constraints that appear to conflict:

**Constraint 1 (Completeness).** The structure must be formalized at
every level at which it can be inspected — mathematics, physics,
biology, phenomenology — or the theory is partial.

**Constraint 2 (Honesty).** No level's formalism can be *assumed* to
describe the others. The identification of structures across levels is
the central epistemic risk of the entire project: it is where
overclaiming lives.

## 0.2 The Resolution: Layers as Independent Inspections

The ochema framework's core methodological claim resolves this:

> **A structure recovered at many independent levels of inspection is
> more likely to be real than a structure recovered at one level.**

This is the **Joint Individuation Principle** (MEPIT Stage 2) and the
**Joint Fixed Point** (Ochema Stage 3):

```
A_i* = Fix(𝕽, 𝕻_i, 𝓤)
```

The bearer is the process-equivalence class on which independently
justified physical descriptions 𝕽 and independently characterized
phenomenal structures 𝕻_i converge.

**Why layers, then?** Because each layer is an *independent inspection*
— a different formalism, a different community, a different mode of
access. The thesis is not one derivation; it is the demonstration that
eight independent derivations recover the same invariants. That is the
justification of the structure of this document: the layers are not
stylistic; they are the evidence.

none was derived from another. That independence is the evidence.

## 0.4 What This Document Does

For each layer: state the formalism, state the key results (with
grades), and state what the layer independently recovered. Then: state
the cross-layer invariants (the structures that appear in every layer),
the inter-layer bridges (what connects adjacent layers, and where the
gaps are), and the master theorem. Then: falsification.
