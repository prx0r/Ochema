# PART 7: FALSIFICATION

The thesis would be seriously weakened if:

1. **A layer fails to recover the structure** — e.g., if a rigorous
   phenomenology of the moment-triad is shown to be incompatible with
   the operator-algebraic triad.
2. **Thermal time fails as physical time** — observed time in a
   generally covariant system demonstrably differs from any modular
   flow.
3. **IIT's Φ-selection and OchemaMath's modular-invariance selection
   are shown to be equivalent** — the one testable divergence in the
   landscape would collapse, and the selection problem would lose its
   distinguishing content (this would not refute the thesis; it would
   remove its most discriminating prediction).
4. **The classical-information layer fails** — if precision weighting
   and the two-stage model are shown not to describe biological
   decision-making.
5. **The χ-gap is closed by a mechanism incompatible with the
   architecture** — if biology→phenomenality is shown to require a
   structure other than the moment-triad/exclusion/invariant.
6. **The orchestration law is experimentally contradicted** — the
   anesthetic dissociation test or an equivalent fails.
