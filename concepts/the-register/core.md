## The Formal Statement

**The register is the state ω of the bearer (M, ω) — the accumulated,
history-carrying configuration of the process that determines what
can be selected.** In the operator-algebraic formalism: ω is a
faithful normal state on the von Neumann algebra M. The register is
not the contents; it is the weighting that selects among them.

**Grade: A (the mathematics — von Neumann algebras, faithful normal
states) / D (the identification with the biological bearer —
untested).**

## The properties (what the register does)

1. **It carries the history** — non-Markovian structure is encoded in
   ω (ochemamath §1.2).
2. **It generates the time** — the modular flow σ_t^ω is a function
   of the state (the time-from-state invariant).
3. **It determines the outcome** — the orchestration law: the state
   at threshold determines what collapses (corollary of thermal time
   + quantum Bayes).
4. **It is shaped, not chosen** — attention is precision weighting;
   the practices (upāyas, bardo training, sleep-prompting) edit the
   register.

## The tradition's statement

"The perceiving subjectivity forever remains true to its own nature"
(Spanda, Stanza 3) — the register as the invariant's bearer. The
Tibetan mind-wind inseparability: there is no state without its
dynamics.
