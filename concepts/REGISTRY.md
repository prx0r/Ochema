## The Concept Pipeline

```
thesis finding → formal core (concepts/<name>/core.md)
    → essay rendering (essays/whattheheckis-<name>-v<N>.md)
    → video (essayviz/skia/FableCut)
    → core updates → re-render → new essay version
```

The essay is the video-ready form of the theorem at its current
state. Core updates produce new essay versions — the explainer is
always current.
