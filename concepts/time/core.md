## The Formal Statement

**Time is the modular flow of the state:**

```
σ_t^ω(A) = Δ^{it} A Δ^{-it}
```

The state ω of a von Neumann algebra generates its own one-parameter
group of automorphisms (Tomita–Takesaki). The state is KMS with
respect to this flow at β = 1. In a background-independent theory,
this flow IS the physical time (Connes–Rovelli thermal time
hypothesis). **The state determines the time.**

**Grade: A (the theorem) / C (the physical-time identification).**

## The Moment-Triad

Time advances in discrete moments. Each moment has three phases:

| Phase | Operator-algebraic content |
|---|---|
| Emergence (sṛṣṭi) | The state evolves; superposition builds |
| Persistence (sthiti) | The modular flow is a group: σ_{t+s} = σ_t ∘ σ_s; the state is KMS-stable |
| Withdrawal (saṃhāra) | A state transition ω → ω′ — the flow is REDEFINED |

**The withdrawal is the moment.** When the state changes, the
time-flow itself changes.

## The Orchestration Corollary

```
τ(ω) = (σ_t^ω)   — the time-structure is a function of the state
```

**The state of the register determines the time of the subject — by
theorem, not metaphor.**

## Adequate Determinism

Deterministic within a regime (the modular flow is a group);
randomness at transitions (state changes). The classical shadow of
the thermal-time structure.

## The Levels of Time (Spanda's three, formalized)

| Level | Content |
|---|---|
| para (no sequence) | The invariant structure; the flow's group structure |
| parapara (the flash) | A single transition — the moment, the "indivisible instant" |
| apara (the sequence) | Emergent macroscopic time — the flow's trajectory |
