## The Formal Statement

**The moment is the state transition — the withdrawal phase of the
triad (emergence → persistence → withdrawal) in which the state
changes and the time-flow is redefined:**

```
ω → ω′,  σ_t^ω → σ_t^ω′
```

**Grade: A (the mathematics — state transitions, modular flows) / C
(the identification with the conscious moment — application). The
triad structure: B (recovered in all eight layers).**

## The Temporal Gap (Bennett's question, answered)

Bennett (2025): is a conscious state at a point in time, or smeared
across time? — declared unresolvable, betting on "at a point."

**The framework's resolution:** the gap's premise is false — there is
no background time in which to smear. The moment is the boundary
between two time-structures (the redefinition of time itself), not a
coordinate point and not a duration. Smearing fails by theorem: a
smeared realization is a finite automaton with trivial modular
structure — no moments at all. Testable via the thermal-time
discrimination experiment.
