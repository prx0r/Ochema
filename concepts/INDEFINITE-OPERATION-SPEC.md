# The Indefinite Operation Spec

## How the Ochema Living Thesis Keeps Running — Forever

> The machinery exists (concept-object, concept-factory,
> confrontation-registry, evidence-registry, ochema-dreaming, acquire).
> This spec answers the question the machinery doesn't: **what keeps the
> loop alive indefinitely?** The queue ends; the gaps close (or don't);
> the corpus stops growing. The spec defines the renewable fuel sources,
> the cadence, the failure modes, and the anti-death rules.

---

## 1. The Core Loop (the heartbeat)

```
        ┌────────────────────────────────────────────────────┐
        ▼                                                    │
  1. REVIEW ──► 2. INGEST ──► 3. CONNECT ──► 4. CONFRONT    │
  (registries)  (new input)  (new links)    (thesis vs theory)│
        │                                                    │
        ▼                                                    │
  5. EVIDENCE ──► 6. PRODUCE ──► 7. LOG/BUMP ────────────────┘
  (attach to   (essay/note/    (version + date)
   claims)      mechanism)
```

The loop must run even on days with zero new input. The fuel for such
days is in §3.

## 2. The Cadence

| Cycle | Frequency | Non-negotiable output |
|---|---|---|
| **Daily dreaming** | 1/day | ≥1 connection found OR ≥1 GAP essay (honest output either way) + LOG entry |
| **Concept factory run** | 2–3/week | 3–5 cores (Stage 1) OR 1–3 essays (Stage 2) per run |
| **Confrontation** | as papers arrive | 1 record per theory, graded, REGISTRY row |
| **Evidence attach** | as papers arrive | 1 record per claim-bearing source, TREE row |
| **Weekly audit** | 1/week | evidence-tree audit + confrontation-backlog check + essay-queue check + thesis refinement check (Friesen rule) |
| **Monthly deep-dive** | 1/month | one unintegrated corpus consumed (Proclus, Iamblichus, Chittick, Steiner, Fuller...) |

## 3. The Renewable Fuel Sources (the anti-starvation design)

The pipeline dies when the input queue empties. Five renewable sources,
ordered by how cheap they are to tap:

### Fuel A — The GAPS (unlimited, self-generating)
The 10 GAPS in evidence/TREE.md are the thesis's own open wounds. Each
gap is a standing research question:
- GAP #1 bearer-identification → every new operator-algebra/neuro
  paper is candidate evidence
- GAP #4 water Λ experiment → any structured-water / coherence paper
- GAP #9 orchestration-law test → any selection/precision paper
**Rule: a GAP is a standing search query. Every dreaming session checks
whether any gap has new candidate evidence.**

### Fuel B — The confrontation backlog (325+ theories, bounded but huge)
Kuhn's *Landscape of Consciousness* taxonomy lists 325+ theories; the
registry has confronted ~15. The backlog is the standing queue:
- Illusionism (Dennett/Frankish), GWT (Baars/Dehaene), HOT (Rosenthal),
  Attention Schema (Graziano), panpsychism (all variants), idealism
  (Kastrup), predictive processing (Friston — partial via IP)...
**Rule: each dreaming session picks one backlog theory, confronts it,
records it. At 1/week that's 6+ years of fuel.**

### Fuel C — The unintegrated corpora (bounded, ~10 major bodies)
Proclus' *Timaeus* (Taylor 1816), Iamblichus' theurgy (Shaw corpus),
Chittick's Sufi corpus, Steiner, Fuller A/B modules + *Critical Path*,
the myth/story project, the yogi database, the 180 research objects'
unread members, the game corpus.
**Rule: the monthly deep-dive consumes one. Each consumption generates
connections + at least one confrontation + one essay.**

### Fuel D — The live frontier (unlimited, self-renewing)
New papers appear daily. The reference folders (576lqg, tegmark,
orch-or, cannon, paulselig, carr, swedenborg, urantia) each have a
standing search: "what's new citing/contradicting this?" The acquire
skill handles ingestion; the confrontation/evidence skills handle
integration.
**Rule: each week, one live-frontier sweep per reference folder.
One new relevant paper per week is conservative; reality gives more.**

### Fuel E — The conversion backlog (finite, but valuable)
Old static whattheheckis docs → live concept-objects:
whattheheckismemory, agency, imagination, subtlebody, channeling,
valence (done), self (done). Each conversion = core extraction + essay
upgrade.
**Rule: convert one per month until the backlog is empty (~6 months),
then the conversions are done — this fuel is finite by design.**

## 4. The Anti-Death Rules (the failure modes and their countermeasures)

| Failure mode | Symptom | Countermeasure |
|---|---|---|
| **Input starvation** | "nothing new to integrate" | Fuel A (GAPS are never empty) — write a GAP essay |
| **Connection fatigue** | "we've connected everything" | The 6 invariants × 8 layers × N corpora is a combinatorially open space; the monthly deep-dive re-opens it |
| **Registry rot** | REGISTRY/TREE drift from reality | Weekly audit fixes before adding |
| **Grade inflation** | essays claim more than cores | The v1.15.1 rule + essay-renders-core-version audit |
| **Pipeline worship** | running the pipeline instead of thinking | The dreaming skill's own warning: if a day produced only logs, the review phase must dig deeper |
| **The queue ending** | QUEUE.md empty | QUEUE.md is NEVER empty by design: completed items leave new candidates behind (every confrontation generates new essay/concept candidates; every GAP generates a new experiment note) |
| **Motivation death** | sessions stop | The content pipeline is the externalized motivation: every essay is a video candidate; every video is published; the publish loop (deploy skill) closes the circle |

## 5. The Queue Regeneration Rule (the key insight)

**The factory's queue never empties because the pipeline is closed-loop:**
every output generates new inputs.

```
confrontation → new evidence rows → new essay candidates
essay → new video candidate → published → reader/reaction → new paper
GAP → experiment note → new search → new paper → new evidence
connection → new mechanism note → new concept candidate → QUEUE grows
```

Concretely, after THIS run (v1.18.0):
- 3 essays pending (exclusion, the self, valence) — Stage 2 fuel
- the memory conversion queued — Fuel E
- 4 concepts queued (boundary, invariant, density, attention,
  recognition) — Stage 1 fuel
- ~310 theories unconfronted — Fuel B
- 10 GAPS standing — Fuel A

**The queue is never empty because the loop's outputs are its inputs.**

## 6. The Self-Correction Loop (the honesty engine)

The most important long-term design: the system must be able to kill
its own claims.

- **The v1.15.1 rule** (no physics-vocabulary grafts onto unfalsifiable
  claims) is checked at EVERY production step — cores, essays, records.
- **The Friesen rule** (a finding can force a thesis change) is checked
  weekly.
- **The falsification section** (the-occhema-object/sections/
  07-falsification.md) is updated whenever a negation strengthens.
- **Evidence asymmetry** (one strong negation outweighs many supports)
  is enforced in TREE.md maintenance.

**A thesis that can't die isn't alive. The indefinite operation spec
includes the permission to falsify — without it, the system would
survive as a monument, not a thesis.**

## 7. The One-Page Summary

```
WHAT RUNS:  the 7-phase dreaming loop, daily
FUEL:       GAPS (never empty) + 310-theory backlog + 10 corpora
            + live frontier + conversion backlog
CADENCE:    daily dreaming · 2-3×/wk factory · weekly audit
            · monthly deep-dive
DEATH PREVENTION: closed-loop queue (outputs → inputs)
HONESTY:    v1.15.1 rule + Friesen rule + falsification section
            + evidence asymmetry — enforced every step
METRIC OF HEALTH: not essay count — GAPS closing, negations recorded,
            thesis versions changing, grades stable under pressure
```

**The system runs indefinitely not because it's always fed, but because
its outputs are its inputs. The queue never ends because every answer
generates a question, every connection a gap, every confrontation a
candidate. The thesis is a loop, and loops don't run out of track.**
